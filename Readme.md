# biz-mcp-gateway

OCR/文档识别 MCP 服务，提供多种图像识别、票据识别、证件识别、车辆识别和宠物识别能力。

## 功能

- 医疗票据查验
  - 电子发票查验
  - 医保电子凭证相关票据查验
  - 异步票据查验
- 证件识别
  - 身份证
  - 银行卡
  - 营业执照
  - 护照
  - 行驶证
  - 驾驶证
  - 户口本
- 医疗文档识别
  - 医疗费用清单
  - 门诊发票
  - 住院发票
  - 病历
  - 化验单
- 通用 OCR
  - 通用文字识别
  - 二维码识别
  - PDF 转图片
- 保单识别
  - 车险保单
  - 寿险保单
- 车辆识别
  - 车牌识别
  - VIN 码识别
  - 车辆登记证书识别
- 医疗知识库查询
- 宠物识别
  - 宠物品种识别
  - 宠物行为识别
  - 宠物鼻纹识别
  - 宠物关键点检测
